Nebula Decision Guide

Integration problems are usually data-contract problems first.

Before connecting systems, define which system owns each fact, how identities reconcile, how updates propagate, and what happens when data is stale, duplicated, or contradictory.

Diagnostic questions

  • Is there a canonical system of record for each entity?
  • Can records be matched across systems without guessing?
  • Are schema changes and migrations versioned?
  • Do analytics metrics have explicit definitions and lineage?
  • For RAG or AI use, is source provenance and access control preserved?
