## 🚀 Get Started Today

### Step 1: Copy Templates (15 min)
1. Copy `sales-ops/LEAD_TRACKING_TEMPLATE.md` to Google Sheets
2. Set up Calendly (free tier)
3. Create HubSpot free CRM account

### Step 2: Publish First Content (10 min)
1. Open `sales-ops/FIRST_WEEK_CONTENT_PLAN.md`
2. Copy Post 1 to LinkedIn
3. Schedule Posts 2-7 for M-F

### Step 3: Start Sourcing Leads (30 min)
1. Use `sales-ops/LEAD_TRACKING_TEMPLATE.md`
2. Google Maps: "dentists near me", "roofing companies near me", etc.
3. Add 50 leads to tracking sheet
4. Begin cold outreach

### Step 4: Deploy Landing Page (1 hour)
```bash
npm install
npm run dev  # Local
# Deploy to Vercel
```
